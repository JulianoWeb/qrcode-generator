# Gerador de QR Code 📱

Gerador simples de QR Code feito em Ruby.

## Funcionalidades

* Gera QR Code a partir de texto ou link
* Salva o QR Code em `.png`
* Permite escolher o nome do arquivo

## Instalação

```bash
gem install rqrcode chunky_png
```

## Como usar

```bash
ruby main.rb
```

Digite o texto ou link e escolha o nome do arquivo.

O QR Code será salvo como uma imagem `.png`.
